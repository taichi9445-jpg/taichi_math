📐 直線の方程式クイズ

点と傾きから直線の方程式を求めよう！

問題 1/5
点（1, 3）を通り、傾きが4の直線の方程式はどれか？
y - 3 = 4(x - 1)
y - 1 = 4(x - 3)
y - 4 = 3(x - 1)
y - 3 = 1(x - 4)
💡 ヒント1

直線の方程式の公式を思い出してみましょう！
点（a, b）を通り、傾きがmの直線の方程式は：
y - b = m(x - a) です。

💡 ヒント2

この問題では：
• 通る点：（1, 3） → a = 1, b = 3
• 傾き：4 → m = 4
公式に代入すると：y - b = m(x - a)

🎉 素晴らしい！完璧です！さすがですね！✨

正解！

点（a, b）を通り傾きがmの直線の方程式は y - b = m(x - a) です。
点（1, 3）、傾き4なので、y - 3 = 4(x - 1) が正解です。

公式をもう一度確認してみてください。
点（a, b）を通り傾きがmの直線の方程式は y - b = m(x - a) です。
この問題の数値を正しく当てはめてみましょう。

問題 2/5
点（-2, 5）を通り、傾きが-3の直線の方程式はどれか？
y - 5 = 3(x + 2)
y - 5 = -3(x + 2)
y + 5 = -3(x - 2)
y - 2 = -3(x - 5)
💡 ヒント1

公式：y - b = m(x - a)
負の数が出てきても、同じ公式を使います。
x - (-2) = x + 2 になることに注意しましょう。

💡 ヒント2

この問題では：
• 通る点：（-2, 5） → a = -2, b = 5
• 傾き：-3 → m = -3
公式に代入：y - 5 = -3(x - (-2)) = -3(x + 2)

🌟 やったー！正解です！頭がいいですね！🧠

正解！

点（-2, 5）、傾き-3なので、y - 5 = -3(x - (-2)) = -3(x + 2) が正解です。
負の座標に注意しましょう。

もう一度考えてみましょう

負の数の扱いに注意してください。
x - (-2) = x + 2 になります。
傾きの符号も確認してみましょう。

問題 3/5
点（0, -1）を通り、傾きが2の直線の方程式はどれか？
y - 1 = 2(x - 0)
y + 1 = 2(x - 0)
y - 0 = 2(x + 1)
y - 2 = -1(x - 0)
💡 ヒント1

公式：y - b = m(x - a)
y座標が負の数の場合、y - (-1) = y + 1 になります。
x座標が0の場合も、(x - 0) の形で書きます。

💡 ヒント2

この問題では：
• 通る点：（0, -1） → a = 0, b = -1
• 傾き：2 → m = 2
公式に代入：y - (-1) = 2(x - 0) → y + 1 = 2(x - 0)

🚀 すごい！天才的な解答です！感動しました！💫

正解！

点（0, -1）、傾き2なので、y - (-1) = 2(x - 0) つまり y + 1 = 2(x - 0) が正解です。
y座標が負の場合は符号に注意しましょう。

もう一度考えてみましょう

y座標が負の数の場合の処理に注意してください。
y - (-1) = y + 1 になります。
公式の形 y - b = m(x - a) を保ちましょう。

問題 4/5
点（3, -4）を通り、傾きが3の直線の方程式はどれか？
y - 3 = 3(x + 4)
y + 3 = 3(x - 4)
y + 4 = 3(x - 3)
y - 4 = 3(x + 3)
💡 ヒント1

公式：y - b = m(x - a)
y座標が負の数の場合、y - (-4) = y + 4 になります。
x座標とy座標を間違えないように注意しましょう。

💡 ヒント2

この問題では：
• 通る点：（3, -4） → a = 3, b = -4
• 傾き：3 → m = 3
公式に代入：y - (-4) = 3(x - 3) → y + 4 = 3(x - 3)

⭐ 最高です！数学の才能がありますね！本当に素晴らしい！🎯

正解！

点（3, -4）、傾き3なので、y - (-4) = 3(x - 3) つまり y + 4 = 3(x - 3) が正解です。
y座標が負の場合の処理がポイントでした。

もう一度考えてみましょう

x座標とy座標を正しく識別してください。
点（3, -4）では、x座標が3、y座標が-4です。
y - (-4) = y + 4 になることに注意しましょう。

問題 5/5
点（-1, -2）を通り、傾きが-2の直線の方程式はどれか？
y - 2 = -2(x - 1)
y + 2 = -2(x + 1)
y + 1 = -2(x + 2)
y - 1 = -2(x - 2)
💡 ヒント1

公式：y - b = m(x - a)
x座標もy座標も負の数の場合：
x - (-1) = x + 1、y - (-2) = y + 2 になります。

💡 ヒント2

この問題では：
• 通る点：（-1, -2） → a = -1, b = -2
• 傾き：-2 → m = -2
公式に代入：y - (-2) = -2(x - (-1)) → y + 2 = -2(x + 1)

🏆 完璧！あなたは数学のマスターです！感激です！👑

正解！

点（-1, -2）、傾き-2なので、y - (-2) = -2(x - (-1)) つまり y + 2 = -2(x + 1) が正解です。
両方の座標が負の場合も、公式通りに代入すれば大丈夫です。

もう一度考えてみましょう

x座標とy座標の両方が負の数の場合の処理に注意してください。
x - (-1) = x + 1、y - (-2) = y + 2 になります。
符号を慎重に確認しましょう。

🎉 クイズ完了！
