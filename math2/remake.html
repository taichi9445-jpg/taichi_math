3乗の展開・因数分解、分数式、組み立て除法。

013乗の展開・因数分解(a+b)3 の展開から a3+b3 の因数分解まで。係数・2文字の応用コースも！まちがえたら3段ヒントで助けてくれるよ。 02分数式の計算約分・かけ算わり算・たし算ひき算の3コース、全31問。因数分解を使って、分数式をスッキリ整理しよう！ 03組み立て除法マスをうめて、商と余りを求めよう。4次式や最高次の係数が1でない式も。最後は剰余の定理でたしかめ！

微分積分 8教材

微分の計算から、接線・増減表、不定積分・定積分・面積まで。

04微分の練習 基礎f(x) を微分して f'(x) を求めよう。xⁿ → 係数 → 分数の係数 → 多項式 → 展開・f'(a) の5レベル！ 05微分の練習 応用多項式の微分を89問。展開してから微分、f'(a) の値、係数を決める問題も。10問モード・超鬼モード・入力モードで勝負！ 06直線の方程式点と傾き、2点から直線の方程式を y＝mx＋n の形で。x軸に垂直な直線や分数の傾きまで全11問！ 07接線の方程式微分して傾きを求め、接線の方程式へ。傾きが与えられる接線、曲線の外の点から引く接線まで全10問！ 08増減表微分 → 因数分解 → 増減表を自分で完成させよう。極大・極小、極値がない関数、定義域つきの最大値・最小値にも挑戦！ 09不定積分練習不定積分を109問から出題。展開してから積分、条件から C を決める問題も。積分定数 C を忘れずに！ 10定積分練習[F(x)] の上端 − 下端を計算しよう。答えが負になる定積分、定積分の性質、1/6 公式まで5モード！ 11面積を求めようグラフで囲まれた面積を定積分で表そう。x軸をまたぐ部分や2つのグラフの間の面積も、目盛りつきの図で考えよう！
